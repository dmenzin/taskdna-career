# Next Best Action

The action planner ranks applications, outreach, reconnection, advice asks, introductions, referrals, sending requested material, follow-ups, waiting, network-gap work, and skill-gap actions.

Priority uses intrinsic opportunity value, access gain, information gain, urgency, readiness, strategic network value, career direction, social cost, and time cost.

Daily plans should balance applications, networking, follow-ups, research, relationship maintenance, and skill work. They should not recommend excessive high-burden asks.
