# Logic parameter registry

The complete as-is inventory, including numbers **not** counted in the official 74, is `docs/COEFFICIENT_REGISTRY.md`.

Inventory generated by `pnpm audit:parameters` into `artifacts/logic_audit/parameters.json`.

This is the human-readable map of the numbers that actually change recommendations.

## Task DNA inference (`scoringConfig.inference`, version `taskdna.v2`)

| ID | Role |
|---|---|
| `evidenceWeightTwoPlus` | Blend weight when two or more dimension signals exist |
| `evidenceWeightSingle` | Blend weight for a single signal |
| `maxEffectiveSignals` | Cap so duplicate evidence cannot buy unbounded confidence |
| `signalConfidenceStep` | Confidence gain per effective signal |
| `sparseEvidenceThreshold` | Evidence-count cliff for the sparse-confidence path |
| `unknownDimensionConfidence` | Confidence when a generic profile has no signal for a dimension |
| `negativeFitPenalty` | Multiplier from repellent risk into displayed Work Fit |

Unknown is not treated as a confident 5. Generic inference uses a neutral prior and `unknownDimensionConfidence`.

Pass 2 added **rules** rather than new scoring coefficients: evidence-class weights (exposure = 0), source-group dependence, work-structure majority-side aggregation, Hireability gap classes, and ask-eligibility gates. `pnpm audit:parameters` still reports **74** free `scoringConfig` numbers. That count did not go down.

## Overall priority (`scoringConfig.weights`)

Displayed Overall is a weighted mix:

`0.40 * Hireability + 0.30 * CAF + 0.15 * Career Direction + 0.10 * Growth + 0.05 * Durability`

then a small visible negative-fit adjustment.

These weights are product judgments. Hireability currently dominates. That is documented, not hidden.

## CAF

`CAF = predictedFit - 2 * (1 - confidence)`

The `2` is `confidenceAdjustedFitPenalty`. It is a heuristic penalty, not a calibrated uncertainty interval.

## Action tiers

Thresholds in `scoringConfig.tiers` are cliffs. A 0.01 change near a boundary can change the label. The debug trace must show the raw numbers so the cliff is inspectable.

## Novelty

Novelty is gated on `minimumRelevantFit` and `minimumCapabilityTransfer` before title-distance can promote a role. Below the gate, novelty is capped under the consumer threshold.

## Network / ask / action

`networkModelConfig.accessWeights`, `pathWeights`, and `actionWeights` plus `askRules.*.socialCost` are uncalibrated social heuristics. They must not alter Work Fit.

## What remains arbitrary

- Dimension keyword lexicons
- Social-cost integers
- Function ontology membership
- Default commute home region (`scoringConfig.commuteRules.defaultHomeRegion`)
