# Relationship model

Relationships store how the user knows a person, shared work, what the contact has observed, memorable context, warmth, trust, familiarity, reciprocity, responsiveness, dormancy, ask fatigue, comfort by ask type, communication style, channel, user read, and explicit boundaries.

The model intentionally avoids a single "network score." Information, routing, credibility, referral, advocacy, readiness, social cost, and confidence are computed separately per opportunity.
