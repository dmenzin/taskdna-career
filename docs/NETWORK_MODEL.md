# Network model

Network nodes include users, people, organizations, teams, work functions, jobs, interactions, applications, opportunities, and ask types.

Edges distinguish direct contacts, employment/association, function relevance, observed capability, routing, referral, advocacy, introductions, and applications. Each path exposes certainty (`CONFIRMED`, `USER_REPORTED`, `INFERRED`, `HYPOTHESIZED`, `SYNTHETIC`).

Synthetic V2 fixtures generate 150+ fictional contacts across 10 personas, including weak ties, dormant ties, recruiters, professors, former managers, explicit offers, boundaries, and second-degree routes.
