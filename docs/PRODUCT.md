# Product

TaskDNA Career helps users discover jobs by recurring work loops instead of lossy titles. The V1 magic moment is a plausible non-obvious match: a job title the user might not search for, but whose actual work structure matches their inferred Task DNA.

The prototype supports demo personas, optional pasted career text, structured evidence, Task-DNA profile, capabilities, work-function ranking, synthetic jobs, job details, reactions, recommendation-change explanations, and debug traces.

All jobs are synthetic demo data. Scores are deterministic heuristic recommendations, not validated psychometrics or labor-market predictions.
