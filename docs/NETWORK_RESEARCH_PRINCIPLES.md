# Network research principles

The principle registry seeds evidence-graded heuristics:

- weak ties can transmit novel job information,
- dormant ties can retain value,
- referrals can carry unobserved candidate information,
- help seekers may underestimate willingness to help,
- informational interviews are useful but not mandatory rituals.

Consumer UI should explain implications plainly. Debug traces can expose principle IDs and evidence grades.
