# Ask ontology

V2 supports asks such as reconnect, career perspective, function insight, role reality, company/team information, who-should-I-talk-to, introduction request, referral request, resume-forward request, recruiter intro, reference, hidden opportunity query, follow-up, thank-you, schedule conversation, and send requested material.

Ask readiness is a vector, not a ladder. Explicit offers can make `SEND_REQUESTED_MATERIAL` the best next ask immediately. Explicit boundaries can block referral asks while preserving information/routing asks.
