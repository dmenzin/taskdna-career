# Debugging

The app includes a debug/product lab section with:

- selected recommendation decision trace,
- profile confidence,
- search funnel counts,
- freshness semantics,
- product hypotheses and limitations.
- raw fit, negative-fit risk, displayed Work Fit, confidence, CAF, hireability, direction, overall, novelty, and score version,
- capability requirements and hard gaps,
- evidence IDs and evidence source types.

For a recommendation, the trace explains evidence profile -> job function -> Task-DNA similarity -> negative-fit penalty -> CAF -> hireability inputs -> direction/growth/durability/novelty -> overall -> tier/sellability.
