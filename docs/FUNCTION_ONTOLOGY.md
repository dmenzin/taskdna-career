# Function ontology

Career functions describe recurring work loops, not occupational titles. The editable V1 ontology lives in `src/config/model.ts` and includes failure analysis, sensor performance, test development, systems debug, engineering tools, real-world algorithm performance, field applications, robotics field performance, controls characterization, scientific software, verification/validation, modeling/simulation, and product systems engineering.

Each function includes a versioned Task-DNA vector, attractors, repellents, typical titles, domains, requirements, and skill gaps.
