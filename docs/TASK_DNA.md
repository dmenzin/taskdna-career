# Task DNA

Task DNA is an extensible vector of work-preference dimensions. V1 includes boundedness, measurable feedback, investigation, evidence density, experimentation, software-as-tool, real-system grounding, causal reasoning, integration, coordination, customer exposure, applied/theoretical orientation, closure, and repetition tolerance.

Each dimension stores value and confidence separately. Low-information users receive lower confidence. Contradictory evidence is surfaced rather than silently resolved.
