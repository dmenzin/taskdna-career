# Outreach execution

Sandbox execution modes:

- `SIMULATE`
- `DRAFT_ONLY`
- `MANUAL_SEND`
- `APPROVAL_REQUIRED_SEND`
- `AUTHORIZED_AUTOMATION`
- `CHANNEL_POLICY_BLOCKED`

V2 does not send messages. LinkedIn is treated as manual only. Email is draft-only in sandbox. Strategy is independent of execution mode.
