# Hireability

Hireability is not work fit. It estimates whether the user's evidence is legible for a specific job today.

Inputs include demonstrated capability overlap, recruiter legibility, seniority mismatch, specialized requirements, and hard gaps. Roles can be high fit but low hireability, or high hireability but low fit.

Sellability categories:

- `DIRECT_SELL`
- `SELL_HARDER`
- `STRATEGIC_STRETCH`
- `REAL_SKILL_GAP`
