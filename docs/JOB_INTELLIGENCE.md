# Job intelligence

The sandbox pipeline is:

raw synthetic observations -> canonical jobs -> hard filter -> semantic screen -> deep analysis -> recommendations.

Every analyzed job receives:

- actual-work one-liner,
- primary and secondary functions,
- Task-DNA vector,
- match and friction factors,
- requirements and hard gaps,
- classification confidence,
- evidence snippets,
- source provenance.

The dataset includes same-title/different-task and different-title/same-task cases to guard against title bias.
