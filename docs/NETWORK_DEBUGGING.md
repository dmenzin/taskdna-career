# Network debugging

For V2, debug surfaces should expose:

- contact and relationship evidence,
- interaction history,
- explicit offers/boundaries,
- information/routing/credibility/referral/advocacy values,
- ask readiness vector,
- social cost,
- path certainty and hop penalties,
- strategy trace,
- execution mode,
- draft grounding fields.

`pnpm eval:network` is the replayable fixture-level sanity check.
