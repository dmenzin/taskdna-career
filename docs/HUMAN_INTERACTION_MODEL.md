# Human interaction model

The strategy order is:

relationship + opportunity + history -> `InteractionPlan` -> deterministic draft -> simulated/manual execution state.

Plans include objective, why this person, relationship interpretation, recommended ask, readiness, burden, social cost, urgency, shared context, facts not to assume, tone, channel, success conditions, follow-up logic, do-not-ask-yet fields, execution mode, and reasoning trace.

The system must be socially normal, specific, and non-manipulative.
