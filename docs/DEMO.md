# Demo

Run the app:

```bash
pnpm dev
```

Recommended walkthrough:

1. Open the home page.
2. Choose "Investigation-oriented failure analyst".
3. Inspect evidence, Task DNA, capabilities, and contradictions.
4. Open ranked functions and filter by a function.
5. Use Job Explorer search and "Non-obvious only".
6. Select a job and inspect actual work, friction, gaps, freshness, and decision trace.
7. React with Love or Dislike and observe the "Your recommendations changed because..." explanation.
8. Open the standalone export at `artifacts/function_map_demo.html` after running `pnpm export:demo`.
